# File placement
Rule: `data/{datasource,model,enums,repository}`, `domain/{entity,use_case}`, `presentation/{screen,view,cubit,widgets,utils}`. Enums one per file: data -> `data/enums/`, presentation-only -> `presentation/utils/enums/`, shared -> `lib/core/enums/`; presentation enum owns `l10n(context)`/`color(context)` as members; data enum's label/icon/color in one extension `presentation/utils/l10n/<enum>_l10n.dart`. Services (device/SDK; interface + impl one file): `lib/core/services/` (`LaunchService`, `LocalStorageService`, `StorageKeys`, `PhotoPickerService` + `PickedPhoto`). Presentation field validators/formatters: `auth/presentation/utils/` (`email_format`, `username_format`, `phone_format`, `birthday`). Pure Dart helpers `lib/core/utils/`. Fonts `assets/fonts/`. Screen provides Cubit; view is the UI and may read its own Cubit (`context.read`, `BlocSelector`/`BlocBuilder` on the smallest widget that needs the state; the screen holds the `BlocListener` for one-shot effects, so typing never rebuilds the page).
Example: lib/features/auth/presentation/
